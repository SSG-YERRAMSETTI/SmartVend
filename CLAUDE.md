# CLAUDE.md

This is an Evolium repository governed by EVO, the Evolium Engineering System.

This file is a thin adapter. It contains no rules of its own.

1. Read `EVO.md` in this repository root. It is the authoritative,
   model-independent engineering contract.
2. If `.evo/` exists, read `.evo/project/context.md` and `.evo/project/state.md`,
   then use `.evo/core/context-map.md` to load only the standards relevant to the
   current task.
3. Follow the significant checkpoint procedure in `EVO.md` section 7 before
   proposing any commit. Wait for explicit human approval before committing or
   pushing.

If `EVO.md` and this file ever disagree, `EVO.md` wins.
